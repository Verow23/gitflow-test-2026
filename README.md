## What is Github flow?

It is a lightweight, branch-based workflow that supports teams and projects where deployments are made regularly. This guide is a reference to the GitHub Flow workflow, which is a simplified version of Gitflow.

## How to use it?

1. Create a branch: Branch off from the main branch to work on a new feature or bug fix. Use descriptive names for your branches, such as `feature/add-login` or `bugfix/fix-header`.

2. Make commits: Make small, focused commits with clear messages that describe the changes you have made. This helps others understand your work and makes it easier to review.
